# Linux Sync

## Setup

Run this: 

```sh
sudo pacman -Syu --noconfirm && \
sudo pacman -S --noconfirm git base-devel && \
git clone https://github.com/DraconicAspirations/linux-bootstrap.git && \
bash linux-bootstrap/bootstrap.sh
```
